# Visualizer · Визуализатор

Add-on helper for SP Imagen. Экспериментальная версия 0.1.0 для SillyTavern.

## Установка
Extensions → Install extension → https://github.com/DatNest/Visualizer → обновить страницу.
Открыть «Визуализатор» в настройках расширений. Шестерёнка также доступна на карточке.

## Возможности
- Сцена, гардероб, постоянная внешность второстепенных NPC, пользовательские поля.
- Названия, метки, промпты и режимы отслеживания настраиваются.
- Профили сохраняются в extensionSettings; выбранный профиль и сворачивание — в chatMetadata.
- Сворачивание по заголовку, вкладки и переключатели записей.
- Вместе с постом либо отдельный запрос через активное подключение или OpenAI-compatible endpoint.
- Метки остаются в исходном mes; скрытие выполняется в DOM.
- HTML-шаблон: {{title}}, {{scene}}, {{wear}}, {{npc}}; значения экранируются. Изолированный iframe, без скриптов.

## Ограничения первой версии
Не проверено на живой установке SillyTavern и SP Imagen. Совместимость зависит от того, читает ли SP Imagen исходный mes. Не отключайте старый рендерер до проверки, но не используйте два генератора одинаковых меток одновременно. Для прямого API необходим CORS; ключ хранится только в sessionStorage текущей вкладки, не в репозитории и не в синхронизируемых профилях. Выбор сохранённых Connection Profiles пока не реализован. Отдельный запрос и запись меток требуют проверки на вашей версии ST. При отключении вывода меток трекинг новых постов сейчас прекращается.
